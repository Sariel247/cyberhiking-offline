# 赛博徒步 · 离线版

> 非官方离线改造项目。当前离线版 v0.3.0，对照官网公开版本 v0.1.55。

## 当前完成

- React + TypeScript + Vite，部署于 GitHub Pages。
- 首页公告、免费塘口起点选择、办公室与塘口开场、红心户外商店。
- 商店四类 48 件物品，65L 背包默认预选，资金与负重校验。
- 驴友之家场景、公告栏公开信、秀才对话、离开建筑/返回驴友之家热点。
- 4 项生存指标：核心体温、体能储备、精神意志、饱腹感。
- 生存面板含 41 个鳌太路线节点、海拔、营地、岔路与行程进度。
- 背包、日记、原地活动、搜寻物资、原地休息。
- 寻人启事事件与照片；后续随机事件复用公开源码中的事件库。
- 本地 LocalStorage 存档、PWA Service Worker 离线缓存。
- 本地程序化环境氛围音，不依赖在线音频文件。
- 山神赐福赞助码「雾尽见山神」：离线兑换后在当前浏览器永久保存权益。
- 黄柏塬镇专属起点：23km 登山口 → 练驴坡 → 导航架，并接入鳌太主线。

## 当前未实现 / 与官网仍有差距

- 账号登录、云端存档与在线支付不在本项目范围内。赞助码仅为本地离线彩蛋，不具备防篡改或商业授权验证能力。
- 都督门下撤已列入赞助者权益状态，但具体路线节点、分支触发和可交互下撤流程仍待路线数据补齐。
- 官网的全部动态天气、完整草药/老药农支线、所有场景插画、完整事件触发条件与音效仍需继续对照和移植。
- 背景氛围音是离线生成的原创环境音，不是官网原始音轨。
- 部分远端背景图片首次访问需要联网；Service Worker 缓存成功后，同一浏览器可离线使用。
- 游戏存档与山神赐福解锁记录均保存在当前浏览器。清理网站数据会同时清除存档、解锁记录和缓存。

## 本地运行

需要 Node.js 20 或更新版本：

- npm install
- npm run dev
- npm run build
- npm run preview

## 山神通行证 · 离线赞助者权益

赞助码：`雾尽见山神`。兑换后在当前浏览器保存本地权益，包含三项权能：

- **先登山径**：记录北坡下撤、厚畛子铺、黄柏塬镇、都督门、太白山景区五条路线资格，并显示每条路线的离线地图接入状态。当前黄柏塬镇路线已接入；其余路线仍需补齐官方路线节点与事件数据，暂不标记为可玩。
- **行囊继承**：每局结束后结算剩余资金，并保存指定高价值装备；下一局开始时继承。背包、外骨骼、帐篷、睡袋、防潮垫、导航仪、卫星电话、相机和望远镜属于当前继承清单。
- **历史刻石**：在本地保存每局结果、天数、功德、地标进度、成就与称号；支持 JSON 导出和导入，便于更换设备或备份。

权益和历史记录均保存在本机浏览器。清除网站数据前请先导出备份。此赞助码为离线彩蛋，不是防篡改的商业授权验证。


- **中途退出结算**：保存并退出会保留当前进度供继续旅程；确认放弃挑战时，若已解锁山神赐福，则会将剩余资金、高价值装备和本局记录结算至行囊继承与历史刻石。
